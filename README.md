# 俄钓查询

AstrBot 的俄罗斯钓鱼 4 查询插件。支持查询用户维护的鱼种上星线、蓝冠线、鱼价、装备价格和上星记录，结果标注来源与更新时间。

**鱼种资料是静态快照**：目前收录 252 个鱼种名称及可核对的上星、蓝冠重量；个别条目没有显示等级线，显示为未知。鱼价、上星点位等数据尚不完整，不提供实时鱼情。俄钓4数据库禁止普通自动程序抓取，钓钓星蓝禁止自动访问 API；本项目不会自动抓取站点数据库。信息可能过期，以游戏内和原站为准。

## 安装与配置

将项目安装到 AstrBot 的 `data/plugins/astrbot_plugin_rf4`，重载插件。默认使用内置静态快照；若 `data/plugin_data/astrbot_plugin_rf4/rf4_data.json` 存在，则改为读取该文件。也可在插件设置里填写本机数据文件路径。复制 `rf4_data.example.json` 作为模板，录入有权使用的数据。修改文件后下次查询自动生效。

```text
/鱼线 白北鲑
/鱼价 白北鲑
/上星 铜湖
/装备 纺车竿
```

数据由管理员维护：更新日期和来源是每条记录的 `updated_at` 和 `source` 字段。缺失的值显示“未知”，不会伪造实时价格。用户应避免发布不具备转载授权的数据。
