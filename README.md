# 俄钓查询 · v1.0.3

AstrBot 的俄罗斯钓鱼4资料查询插件。内置251条鱼种、19张地图清单和国际绝对榜快照，QQ以纯文本回复。

## 使用

```text
/鱼线 欧鳊
/鱼价 白北鲑
/上星 铜湖
/装备 纺车竿
```

搜索优先精确匹配名称，其次精确匹配别名；均未命中时才模糊搜索，最多返回5项。`/鱼线 欧鳊`只返回欧鳊，输入部分名称仍可查找候选。

鱼种输出依次为：

```text
欧鳊  ⭐上星 4.4 kg  ✨蓝冠 7 kg
重量（参考）：0.05 kg～7.999 kg
分布：水域名称（最大 尚未明确）
　　　其他水域（最大 尚未明确）
榜单记录（国际绝对榜（来源站快照），快照日期）：重量，来自 水域，饵料：名称
```

示例用于说明排版，水域及纪录以查询返回为准。所有未确认字段显示“尚未明确”，水域条数随鱼种变化。

## 安装与升级

从Release下载 `astrbot_plugin_rf4-v1.0.3.zip`，通过AstrBot安装，或覆盖 `data/plugins/astrbot_plugin_rf4` 后重载。要求AstrBot >=4.11.0，无新增第三方依赖。

默认读取内置快照。若 `data/plugin_data/astrbot_plugin_rf4/rf4_data.json` 存在，则优先读取该文件；也可以在设置填写自定义文件路径。升级会继续使用已有自定义数据，要使用新版内置数据，请备份后移走自定义文件，并清空自定义路径。不要卸载清理数据。

## 数据说明

按维护者要求移除了“小欧鳊”。251条鱼种均有已核对水域及国际绝对榜快照，地图共614条关联。重量范围为社区参考值；部分最小和最大值、各水域最大重量及三个七鳃鳗的蓝冠值尚未明确。

榜单是来源站的静态快照，24条日期为2026-10-30、227条为2026-10-13，回复按各条快照日期显示。部分商品饵名保留英文。鱼价、装备和上星点位指令保留，但内置相关资料仍不完整，不提供实时价格或鱼情。

数据来源、范围和许可说明见 [DATA_SOURCES.md](DATA_SOURCES.md)，具体缺失清单见 [data/missing_fields.json](data/missing_fields.json)。如需维护数据，参照 `rf4_data.example.json`；修改文件后下次查询生效。

## 饵料本地化

饵料对照保存在 `data/bait_names.json`，逐条保留中文、英文、俄文及来源。中文游戏中沿用英文的商品名原样显示；未核实的保留原文并标注“尚未明确”。现用143个不同饵名已确认45个中文显示名，其余仍待补，不强行翻译。词库结构和覆盖范围见 [BAIT_NAMES.md](BAIT_NAMES.md)。
